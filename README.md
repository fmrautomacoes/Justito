# Justito

A conta do bar dividida do jeito justo. Hey Tito!

Versão de teste da Fase 1: app web instalável (PWA), sem login, com os dados salvos no próprio celular.

- `index.html`: o app inteiro (HTML, CSS e JavaScript)
- `manifest.webmanifest`, `icon*.png`, `icon.svg`: instalação na tela inicial
- `sw.js`: funciona sem internet
